# Dependência Externa

- **Serviço de Notificação**  
O sistema de notificação possui dependência externa de serviços de mensagens como email e whatsapp para efetuar o serviço de enviar notificação para o usuário. Isso significa que, se o usuário não possuir estes serviços ou não cadastrar no sistema, não tem como o sistema enviar os avisos aos usuários.

- **Serviço de Gestão Acadêmica**  
O módulo de Integração acadêmica também possui dependência de serviços externos. Caso a universidade ou outras instituições de ensino já possua algum sistema de ensalamento ou similares, o módulo consegue trazer os dados e atualizar dentro do seu sistema. Mas se a instituição não possuir o sistema próprio, este módulo acaba sendo inutilizável dentro do sistema.
