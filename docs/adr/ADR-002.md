**ADR-002:** Estratégia de evitar reservas duplicadas.
**Contexto:** O sistema permite que usuários possam realizar reservas de salas em horários específicos. Entretanto, existe a possibilidade de dois ou mais usuários tentarem reservar o mesmo espaço no mesmo horário, ocasionando conflitos de reservas duplicadas.
**Alternativas:**
- Verificação apenas na aplicação: o sistema consulta se a sala está disponível antes de registrar alguma reserva.
- Controle por transações no banco de dados: utilizar transações para controlar as operações de reserva e evitar inconsistências durante operações simultâneas.
- Restrições de integridade no banco de dados: utilizar restrições que impeçam a existência de reservas conflitantes para a mesma sala e horário.
**Decisão:** Será adotado um mecanismo de controle de concorrência utilizando transações no banco de dados e restrições de integridade para impedir reservas conflitantes. 
**Consequências:** 
- **positivas:**
	- Evita reservas duplicadas para uma mesma sala e horário.
	- Reduz conflitos entre usuários.
	- Garante maior consistência e integridade dos dados.
- **negativas:**
	- Pode aumentar o tempo de resposta em situações de alta concorrência.
	- Pode ocorrer bloqueio ou espera entre operações simultâneas.
	- A implementação das restrições pode aumentar a complexidade do banco de dados.
